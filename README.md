# حاسبة الهند – النخبة

تطبيق عربي باتجاه RTL لحساب نقاط لعبة الهند بالجنجفة لفريقين أو ثلاثة أفرقة، أو لثلاثة إلى خمسة لاعبين فردياً. يعمل مباشرة في المتصفح باستخدام HTML وCSS ووحدات JavaScript، ويحفظ المباراة في LocalStorage على المتصفح نفسه.

## التشغيل المحلي

شغّل خادم ملفات من جذر المشروع باستخدام Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

افتح [التطبيق المحلي](http://127.0.0.1:8000). يعمل التطبيق بلا تثبيت حزم. يُحمّل خط Noto Kufi Arabic من Google Fonts عند توفّر الاتصال ويستخدم خط النظام عند تعذّر التحميل.

## الاستخدام

1. اختر نظام اللعب وعدد المشاركين، ثم أدخل الأسماء وابدأ المباراة.
2. اختر نوع الفوز تحت اسم الفريق الفائز. عيّن النزول لكل فريق خسران وأدخل نقاط الورق المتبقي لكل لاعب نازل. اختر الشرهة عند الحاجة، وسجّل الإعلان الفاشل لكل خسران معني.
3. راجع النقاط واضغط «اعتماد اللعبة». استخدم «تعديل» أو «حذف» في السجل، أو «التراجع عن آخر لعبة» لحذف أحدث لعبة معتمدة. اضغط قلم النقاط لتصحيحها قبل الاعتماد أو من سجل اللعبات، أو لاستعادة الحسبة التلقائية.
4. بعد اكتمال العدد المحدد، تظهر النتيجة النهائية. يفوز صاحب أقل مجموع، ويُعرض جميع المتعادلين في المركز الأول.

إذا خفّض تعديل أو حذف حد المباراة إلى خمس لعبات، تبقى النتائج الزائدة في السجل بحالة «معلّقة»، وتخرج من المجموع. تعود إلى الحساب عند امتداد المباراة مجدداً. يمكن تعديل اللعبات المعلّقة أو حذفها مثل باقي اللعبات.

## الاختبارات

يتطلب تشغيل الاختبارات Node.js 18 أو أحدث:

```sh
node --test
```

يحتوي `scoring.mjs` على قواعد الحساب وإدارة النتائج والحفظ، وتحتوي `app.mjs` على التفاعل مع واجهة المستخدم. تغطي اختبارات `tests/scoring.test.mjs` جدول النقاط والنزول والشرهة، والتحقق من المدخلات، وحد اللعبات، والتعديل والحذف والتراجع، والتعادل، والحفظ والاستعادة.

## النشر على GitHub Pages

بعد الموافقة على النشر، ارفع ملفات المشروع إلى فرع `main` في المستودع. افتح **Settings → Pages**، واختر **Deploy from a branch**، ثم **main** والمجلد **/(root)** واضغط **Save**. يعرض GitHub عنوان الموقع بعد اكتمال النشر. تستخدم الصفحة مسارات نسبية وتعمل من عنوان المشروع الفرعي دون إعداد خادم خلفي.

[دليل إعداد مصدر النشر في GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
