# حاسبة الهند – النخبة

تطبيق عربي باتجاه RTL لحساب نقاط لعبة الهند بالجنجفة لفريقين أو ثلاثة أفرقة، أو لثلاثة إلى خمسة لاعبين فردياً. يعمل مباشرة في المتصفح باستخدام HTML وCSS ووحدات JavaScript، ويحفظ المباراة في LocalStorage على المتصفح نفسه.

## التشغيل المحلي

شغّل خادم ملفات من جذر المشروع باستخدام Python 3:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

افتح [التطبيق المحلي](http://127.0.0.1:8000). يعمل التطبيق بلا تثبيت حزم. يُحمّل خط Noto Kufi Arabic من Google Fonts عند توفّر الاتصال ويستخدم خط النظام عند تعذّر التحميل.

## الاستخدام

1. اختر نظام اللعب وعدد المشاركين، ثم أدخل الأسماء وابدأ المباراة. عند اختيار فريقين، اختر جيكرين أو ثلاث جياكر.
2. اختر نوع الفوز تحت اسم الفريق الفائز. عيّن النزول لكل فريق خسران وأدخل نقاط الورق المتبقي لكل لاعب نازل. اختر الشرهة عند الحاجة، وسجّل الإعلان الفاشل لكل خسران معني.
3. راجع النقاط واضغط «اعتماد اللعبة». استخدم «تعديل» أو «حذف» في السجل، أو «التراجع عن آخر لعبة» لحذف أحدث لعبة معتمدة. اضغط قلم النقاط لتصحيحها قبل الاعتماد أو من سجل اللعبات، أو لاستعادة الحسبة التلقائية.
4. بعد اكتمال العدد المحدد، تظهر النتيجة النهائية. يفوز صاحب أقل مجموع، ويُعرض جميع المتعادلين في المركز الأول. ينهي «هند زات» المباراة فور اعتماده ويمنح الفوز لصاحبه دون إضافة نقاط.

إذا خفّض تعديل أو حذف حد المباراة إلى خمس لعبات، تبقى النتائج الزائدة في السجل بحالة «معلّقة»، وتخرج من المجموع. تعود إلى الحساب عند امتداد المباراة مجدداً. يمكن تعديل اللعبات المعلّقة أو حذفها مثل باقي اللعبات.

## الاختبارات

يتطلب تشغيل الاختبارات Node.js 18 أو أحدث:

```sh
node --test
```

يحتوي `scoring.mjs` على قواعد الحساب وإدارة النتائج والحفظ، وتحتوي `app.mjs` على التفاعل مع واجهة المستخدم. تغطي اختبارات `tests/scoring.test.mjs` جدول النقاط والنزول والشرهة، والتحقق من المدخلات، وحد اللعبات، والتعديل والحذف والتراجع، والتعادل، والحفظ والاستعادة.

## النشر على GitHub Pages

بعد الموافقة على النشر، ارفع ملفات المشروع إلى فرع `main` في المستودع. افتح **Settings → Pages**، واختر **Deploy from a branch**، ثم **main** والمجلد **/(root)** واضغط **Save**. يعرض GitHub عنوان الموقع بعد اكتمال النشر. تستخدم الصفحة مسارات نسبية وتعمل من عنوان المشروع الفرعي دون إعداد خادم خلفي.

[دليل إعداد مصدر النشر في GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## إصدار الحاسبة

عند نشر إصدار جديد، حدّث رقم الإصدار في وسم `calculator-version` وفي التذييل وروابط CSS ووحدات JavaScript في `index.html`، وفي رابط استيراد `scoring.mjs` في `app.mjs`. تتحقق الحاسبة من الإصدار المنشور عند الفتح والعودة إليها، ويعيد زر التحديث تحميل الصفحة من المصدر نفسه. تُحفظ بيانات المباراة في التخزين المحلي للمصدر نفسه.

## مشاركة القيد المباشر من الآيفون

تستخدم [نسخة الاختبار](https://hand-calculator-live-preview.web.app/) مشروع Firebase منفصلاً على خطة Spark، مع Realtime Database في بلجيكا ومصادقة مجهولة لمتصفح صاحب المباراة. إعداد Firebase مفعّل على الرابط الرسمي وعلى نطاقَي استضافة المعاينة والخادم المحلي.

1. افتح رابط نسخة الاختبار في Safari على الهاتف الأول، وابدأ مباراة واضغط «مشاركة القيد» بجانب «إعادة المباراة» ثم «مشاركة عبر واتساب».
2. افتح رابط المباراة في الهاتف الثاني. اعتمد لعبة وعدّل النقاط والأسماء، ثم تراجع وأكمل المباراة. يتحدّث القيد دون إعادة تحميل وتظهر احتفالية الفوز عند اكتمال المباراة.
3. اضغط «إيقاف المشاركة المباشرة» من هاتف صاحب المباراة. يفقد المشاهد وصوله إلى القيد فوراً.

توجد صلاحيات قاعدة البيانات في `database.rules.json` وإعدادات تطبيق المعاينة في `live-config.mjs`. عند تحديث المعاينة عبر Firebase Hosting، انشر ملفات الواجهة إلى مشروع `hand-calculator-live-preview` واستخدم `firebase deploy --only hosting --project hand-calculator-live-preview` من مجلد استضافة المعاينة. يمكن استخدام Cloud Shell في Firebase Console من المتصفح.

كل من يحصل على رابط المشاهدة يستطيع رؤية الأسماء والنتائج المعتمدة. يعتمد التحكم بالمشاركة على هوية Firebase المحفوظة في متصفح صاحب المباراة، لذلك احتفظ ببيانات الموقع في المتصفح طوال المباراة. يتوقف الرابط عند الضغط على «إيقاف المشاركة المباشرة» أو تأكيد بدء مباراة جديدة أو إعادة المباراة. عند اكتمال المباراة يبقى الرابط متاحاً حتى يوقفه صاحبها. إذا حُذفت بيانات متصفح المالك، يستطيع مشرف مشروع Firebase حذف سجل المشاركة من تبويب **Data**.
